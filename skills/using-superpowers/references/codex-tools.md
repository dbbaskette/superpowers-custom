# Codex tool adaptation

Use the actual tools exposed by this session; names, parameters, model support, and permission
rules may differ by version. Do not edit config to enable delegation or change model defaults
unless requested. Prefer inherited model settings unless a supported override is authorized.
Use focused task context for independent workers and existing follow-up tools when resuming one.

Keep useful local work moving while workers run. Otherwise use bounded event waits and the
host's communication cadence; do not force five-minute silent waits or busy polling.
Check repository/worktree/branch identity before Git mutations. Detached HEAD and sandbox
restrictions should be handled through actual available host tools, not assumed capabilities.
