# Implementer brief

Provide task/spec, dependencies, allowed files/actions, workspace, and verification ownership.

Implement the assigned outcome and appropriate regression coverage. Read relevant code as
needed; adapt mechanics without changing scope. Run focused milestone checks and report command,
tested state, result, and limitations. The coordinator owns integrated final tests unless the
brief explicitly assigns them here. Do not spawn other workers or reviewers unless authorized.
Do not commit, publish, or use external services unless the brief grants that scope.

Continue safe local diagnosis and repairs without per-step approval. Ask for missing material
decisions or authority, not ordinary uncertainty the code can resolve. Report DONE only when
acceptance criteria are met; otherwise report incomplete work, blocker, and what was tried.
